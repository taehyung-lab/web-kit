# 제품 정책

화면을 만들 때 기준이 되는 제품 원문과 사용자 결정을 이 폴더에 둔다. 코드와 키트 문서는 "어떻게"를, 이 폴더는 "무엇을"을 맡는다.

여기에 둘 것:

- 화면별 정책: 목록 검색 기본값·URL key·정렬, 입력 제약, 확인창이 필요한 작업, 권한별 노출, 업무 규칙(예: 일괄 작업 한도)
- 문구 원문과 실패 안내 방침
- 결정과 결정권자, 아직 열린 질문

두지 않을 것: 키트 사용 방법(설치된 web-kit 스킬이 맡는다), 작업 진행 기록(`work/`), 코드에서 바로 읽히는 사실.

지금은 비어 있다. 예시 화면(`src/features/products`)의 값은 스타터가 정한 예시이며 제품 결정이 아니다.

# 작업 지도

결정·의존·완료 조건이나 대상·근거를 대화만으로 놓칠 위험이 있을 때 쓴다(크기가 아니라 놓칠 가능성으로 고른다).

- 위치는 `work/<작업명>/work.md`(AGENTS.md 프로젝트 절이 다른 경로를 정했으면 그 경로). 질문을 보내기 전에 쓰고, 끝나면 재사용할 결정을 반영해 정리한다.
- `## 맥락`: 대상(저장소·경로·커밋), 근거(경로·버전·용도), 범위 안·밖, 시나리오 전·행동·후, 위임별 작성권. 시작·대상 변경·재개·정정 때 바뀐 항목만 고치고 위임·검토에 함께 넘긴다. 비밀값은 적지 않는다.
- `## 기준`: `요청 원문`(사용자 글 그대로, 후속 글 포함)과 요구 기록 표 `ID | 요구(입력→관찰 장소→기대) | 출처·위치 | 의존 | 확인 방법 | 상태`.
  - 상태는 확정·미정(사용자 답)·미확인(조사). 출처가 결과 일부만 정하면 행을 나눠 나머지를 미정으로 둔다. 내 읽기가 출처인 행은 사용자가 확인하기 전까지 미정이다. 미정·미확인에 의존하면 확정이 아니다.
  - 확인 방법은 요구를 어기면 실패해야 한다. 범위 밖은 넣지 않는다.
- 쓰거나 고친 뒤 `python3 .agents/skills/wf-verify/verify.py record --map <지도>` 로 형식과 남은 미정을 본다. 종료 0은 형식 검사 성공이며, open_decisions가 남으면 묻고 unconfirmed는 조사한다. 완료 판정은 이 명령이 맡지 않는다.

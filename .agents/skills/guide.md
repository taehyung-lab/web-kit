# 선택 안내: 작업 지도·맥락 봉투·질문·독립 검토

AGENTS.md 의 기본 기준만으로 부족할 때 해당 절만 읽는다. 매 작업에 쓰지 않는다.

## 작업 지도: 결정·의존·완료 조건을 대화만으로 놓칠 위험이 있을 때

크기가 아니라 놓칠 가능성으로 고른다. 예: 정책이 충돌하거나 요구가 얽힌 일, 여러 턴·세션에 걸친 일, 남에게 넘길 일.

- 위치는 `work/<작업명>/work.md`. 사용자 몫의 미정을 묻기 전에 쓴다. 끝나면 재사용할 결정을 반영하고 지도를 정리한다.
- `## 기준`에는 필요한 만큼만: `요청 원문`(사용자 글 그대로, 뒤 메시지가 결과·범위를 바꾸면 그것도) → 사용자가 볼 결과(입력 → 관찰 장소 → 기대) → 지켜야 할 기존 보장과 연결 근거 → 확인 방법(조건을 어기면 검사가 실패하는지 포함). 미정은 질문과 추천으로 따로 둔다.
- 설계와 실행 결과는 `## 기준` 밖에 둔다. 구현 방법·증거를 고치는 것은 다시 묻지 않고, 사용자가 정한 결과·범위와 다르게 `## 기준`을 바꿔야 하면 확인한다.

## 맥락 봉투: 대상·근거·결정을 놓칠 위험이 있을 때 (지도의 `## 맥락`, 짧은 일은 대화 몇 줄)

- 대상(결과를 둘 저장소·경로, 커밋·변경 여부)과 근거(경로·버전·용도: 현재 결정 / 과거 비교 / 연결 예). 근거는 현재 파일과 대조한 뒤 쓴다.
- 범위 안·밖, 시나리오 전(이미 성립한 것)·행동·후(다음 단계가 받을 것), 결정 확정·미정·보류와 출처, 작업·위임별 작성권(쓰는 경로).
- 시작·대상 변경·재개·사용자 정정 때 `python3 .agents/skills/wf-context/context.py inspect`(경로·커밋·변경·키트 버전)로 바뀐 항목만 고친다. 새 턴이라는 이유만으로 다시 조사하지 않는다. 비밀값·env 내용은 적지 않는다.
- 위임·인계·검토 입력에 봉투(인계는 증거·남은 일까지)를 넣고 받았는지 확인한다. 독립 분석 단계는 원문·봉투·근거만, 교차 리뷰 단계는 상대 산출물까지 읽는다고 적는다.

## 질문: 사용자 몫의 미정이 남았을 때

미정을 셋으로 나눈다. 원문·결정으로 정해진 것(다시 묻지 않음), 조사·실행으로 정할 것(직접 정하고 근거를 적음), 사용자 몫(결과·범위·권한·완료 기준이 갈림). 사용자 몫만 지금 행동·다음 단계에서 달라지는 결과와 추천 이유를 붙여 묻는다. 질문의 전제는 봉투의 대상·시나리오 안에 둔다. 앞 답에 따라 달라지는 결정은 답을 받은 뒤 묻는다.

## 독립 검토: 직접 확인만으로 확인하기 어려운 공백이 있을 때

고르는 이유를 한 줄로 밝힌다: 어떤 보장이 깨질 수 있고 직접 검사로 무엇을 확인하기 어려운가. 사용자 요구, 검사를 지우·건너뛰·약화하는 기준 변경은 반드시 받는다.

1. `python3 .agents/skills/wf-verify/verify.py prepare --map work/<작업명>/work.md` (지도가 없으면 사용자 글 그대로의 파일로 `--request <파일>`, 작업 전 커밋이 HEAD 가 아니면 `--base <커밋>`, 분석·설계만 했으면 산출물 `--output <파일>`). 요청 원문·`## 기준`·`## 맥락`·맥락 도구 출력·변경(diff)이나 산출물을 묶어 `prompt_file` 을 낸다. 요청 원문·기준·검토할 것이 없으면 입력 부족(미확인)이다. 요약한 계획으로 대신하지 않는다.
2. `prompt_file` 을 그대로 하위 에이전트(검토자)에게 맡긴다. 검토자는 대상 폴더에서만 읽고 검사를 돌린다.
3. 검토자의 마지막 답을 고치지 않고 `verify.py finish --round <kept>` 의 표준 입력으로 넘긴다. ok 만 통과다.
4. returned 면 사유를 원문·기준과 대조해 원인 자리로 돌아간다(요구 정의·설계·코드·검사, 사용자 몫이면 질문). 고친 뒤 prepare 부터. incomplete 는 미완료, unverified 는 사유·재개 조건과 함께 보고한다.

검토자 기준: 판정 범위는 바꾼 동작·산출물과 연결 근거가 있는 기존 보장이다. 요구의 근거는 사용자 원문과 외부 계약뿐이고 구현자의 자기평가는 근거가 아니다. 새 요구가 있어야 성립하는 반례는 범위 밖으로 따로 적는다. 판정 중에는 아무것도 고치지 않는다.

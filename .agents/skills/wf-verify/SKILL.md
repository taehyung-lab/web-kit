# 독립 판정

1. 구현하지 않은 검증자가 맡는다. 개인 작업에서는 같은 모델의 별도 새 세션도 가능하다. 모델이 같으면 같은 오류를 반복할 수 있으므로 실제 결과와 원문 근거로 판정한다. 전체 담당자는 대상 버전·변경물·실행 방법과 확정 조건·원문 근거·승인된 기준 변경만 골라 넘기고, 구현자의 충족 판정·자기평가는 검증자가 독립 판정을 기록한 뒤 대조한다. 확정된 조건을 원문 근거와 대조해, 조건 밖 누락이나 근거 없이 정해진 조건을 발견하면 판정하지 않고 설계로 돌려보낸다.
2. 대상 버전·환경을 고정하고 조건별 실제 결과와, 조건을 어긴 사례를 새 검사가 실패로 판정하는지 확인한다. 판정 도중 작업 트리나 대상이 바뀌면 그 판정은 무효로 하고 다시 본다. 기준 변경 항목은 근거와, 검사가 바뀐 기준의 충족과 위반을 구별하는지 다시 본다.
3. 판정 중 기준·제품 코드를 바꾸지 않는다. 증거 재사용은 변경 영향과 환경이 여전히 유효한 이유가 있을 때만 한다.
4. 실패는 기대·실제·재현과 확인된 원인을 붙여 그 부분을 책임지는 곳에 돌리고, 수정 뒤 실패와 영향을 다시 확인한다. 원인 미상은 추측으로 닫지 않는다.
5. 조건별 판정·근거·남은 행동을 전체 담당자에게 넘긴다.

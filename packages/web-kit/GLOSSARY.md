# web-kit

공용 키트를 사용할 때 혼동하기 쉬운 개념을 구별한다.

**결과 출처**: 표시 중인 조회 결과가 어떤 확정 검색 조건에서 나온 것인지의 관계다. 현재 조건의 결과가 아니면 선택·쓰기 대상으로 쓸 수 없는 이유가 된다.

**목록 복귀 문맥**: 상세·수정 등으로 이동하기 직전 목록의 주소와 검색·정렬·페이지를 다시 찾는 데 필요한 정보다. 표시 중인 데이터의 결과 출처와 별개다.

**설치 기록**: 어떤 공용 원본을 프로젝트 어디에 설치했는지와, 설치 직후의 기준본을 식별하는 정보다. 이후 프로젝트 수정과 원본 변경을 구별하는 출발점이다.

**검사 실행 기록**: 어떤 입력 상태에서 실행한 검사가 어떤 결과를 냈는지 연결하는 정보다. 설치 당시의 기준본과 현재 검사한 수정본은 서로 다를 수 있다.

# 0002. 공통 동작과 선택적 기본 UI를 같은 키트에서 관리한다

- 상태: 대체됨 (2026-10-27) — [0003](0003-web-kit-3-redesign.md)이 전부 대체한다.
- 관련 결정: [0001](0001-web-kit-1.0.md)의 「시각 UI는 프로젝트 소유」를 아래 소유 구분으로 대체한다. core 정의와 기존 수명 보장은 유지한다.
- 이 기록은 소유권과 구조 선택의 이유를 맡는다. 구현된 기능은 공개 코드, 사용 보장은 같은 버전의 스킬과 검사에서 확인한다.

## 맥락

공통 동작만 제공하고 입력·오류·확인창의 연결을 소비자마다 다시 만들면, 같은 접근성·상태 처리의 결함을 여러 곳에서 고치게 된다. 공통 기본 UI까지 제공하되 업무 의미와 서버 계약을 끌어들이지 않는 구조가 필요하다.

기존 구현의 차이는 공통화 가능성을 판단하는 자료다. 기본 상호작용의 차이는 하나의 표준으로 정리하고, 실제 업무 의미가 다른 부분은 소비자 입력과 조립으로 남긴다.

## 결정

1. 키트는 공통 동작과 기본 UI의 표준을 소유한다. 필수 표시·오류·이탈 차단·필터·목록 같은 기본 상호작용은 소비자별 과거 동작을 모두 옵션으로 보존하지 않고 일관된 기준으로 제공한다. 업무 조건·권한·문구·서버 계약은 소비자가 소유한다.
2. 순수 core, 실행 동작, 라이브러리 연결, 기본 UI는 책임과 import 방향으로 구분하며 현재 패키지·저장소를 유지한다. 물리적 분리는 실제 설치·배포 요구가 생길 때 판단한다.
3. 기본 UI는 공통 동작을 소비하며 동작 module은 기본 UI를 import하지 않는다. UI를 교체해도 세션·검색·저장 수명을 다시 구현하지 않는 seam을 유지한다.
4. 선택적 UI란 필요한 기능을 선택해 사용한다는 뜻이다. 채택한 기능의 기본 보장을 소비자가 다시 정한다는 뜻은 아니다. 표현 차이는 디자인 토큰과 내용 조립으로 다루고, 별도 동작은 관찰된 필요가 있을 때 설계한다.
5. 공용 편입은 프로젝트 개수나 코드 모양이 아니라 책임·수명·실패와 수정 비용으로 판단한다. 접근성·실패 처리·상태 보존을 개선하는 보장은 공통 기준에 포함한다.

## 소유 범위

| 책임 | 키트 | 소비자 |
|---|---|---|
| 기본 입력·다이얼로그 | 값 연결·접근성·키보드·focus·열림 표현 | 문구·업무 의미·실행할 업무 |
| 필터 | 입력·배치·검색/초기화 상호작용·초안 수명 | 필드·기본값·기간의 업무 의미·필수 조회 조건 |
| 목록 | 결과 상태·표·정렬/선택 표현·페이지 이동 | 컬럼·조회·선택 가능 조건·행 이동·일괄 작업의 업무 결과 |
| 상세 | 레코드 상태·항목/구역·재시도 표현 | 항목 구성·마스킹 노출 정책·권한·이동 |
| 폼 | 저장 수명·검증 오류·필수 표시·입력 연결·배열 입력·기본 이탈 차단 | 업무 검증·요청 변환·완료 후 업무 절차 |
| 연결 | 공통 보장·adapter 검사 | 저장 위치·읽기 불가 정책·서버 결과 코드·운영 헤더 |

## 검토한 대안

| 대안 | 판단과 대가 |
|---|---|
| 모든 시각 UI를 소비자가 구현 | 같은 연결·접근성 처리를 반복하므로 기본 UI 재사용의 이점을 얻지 못함 |
| 기존 공용 폴더를 그대로 합침 | 업무 문구·정책·서로 다른 상태 수명이 공용 interface에 섞임 |
| core/동작/UI를 먼저 독립 저장소로 나눔 | 저장소 추가만으로 동작 중복이 줄지 않고 버전 조합 관리가 늘어남 |
| 같은 키트에 선택적 기본 UI 제공 | 채택. 공통 수정의 locality와 재사용 leverage를 얻는 대신 표현과 동작의 의존 방향을 지켜야 함 |

## 재검토 조건

- 다른 실행 환경이나 독립 배포 주기가 생겨 현재 패키지의 의존성이 실제 사용을 막는다.
- 소비자가 공통 보장을 유지하면서도 기본 UI로 표현할 수 없는 요구를 반복해서 만난다.
- 제품별 옵션이나 업무 분기가 늘어 공용 interface의 이해 비용이 직접 구현보다 커진다.

특정 소비자의 비교 결과·이전 목록·구현 진행 상태는 이 결정의 정본이 아니다. 해당 작업 기록에서 관리하고, 완료된 공통 보장은 코드·스킬·검사에 반영한다.

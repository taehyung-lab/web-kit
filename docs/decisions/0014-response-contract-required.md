## 결정과 이유

서버 응답 형식은 소비 프로젝트가 명시적으로 선택한다. 기존 Spring 해석은 이름 있는 선택 부품으로 옮기고, 공통 요청 입구의 생성 봉투 타입 전제도 제거한다. Spring이 아닌 서버의 정상 응답이 봉투 해석 실패가 되는 문제를 원래 기본값 자리에서 해결한다. 생략 허용이나 예외 플래그는 추가하지 않는다.

이 변경은 응답 입력과 요청 공개 타입을 바꾸므로 5.0의 사용 계약 변경에 함께 묶는다. rc.1 파일을 소비처가 이미 받은 상태이므로 같은 이름의 내용을 교체하지 않고 `5.0.0-rc.2`로 구별한다. DT·REF 적용과 실서버 확인은 별도 작업이다.

## 관문 분리

확인과 재전송은 종류별로 막는다. 느린 확인 중에도 재전송을 별도로 실행할 수 있게 한다(2026-10-29 사용자 원칙 적용).

## 실패 값 분리

확인·재전송 실패를 각각 소유하고 각 종류 시작은 자기 실패만 지운다. 재전송이 기존 확인 오류를 지우지 않게 한다(2026-10-29 사용자 원칙 적용).

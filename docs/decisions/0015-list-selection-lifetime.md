# 0015. 목록 검색 실행과 선택 수명, 트리 저장값 보존

- 결정일: 2026-10-30
- 결정권자: 사용자
- 대상: 5.0.0-rc.3

사용자가 2026-10-30 “1·2·3번 묶어서 rc.3로 진행”을 승인했다. 분석 근거는 다른 세션의 미추적 분석 문서이며, 그 문서를 배포 근거나 정본으로 복제하지 않는다.

사용자 검색 실행과 배경 재조회를 구분하기로 했다. 같은 조건 검색에서도 이전 응답이 남아 체크와 일괄 변경이 가능했고, URL만으로 구분하던 선택 수명은 이 실행을 식별하지 못했다. 따라서 검색 실행을 상태 소유자가 추적하는 방식으로 정했다.

트리에 없는 기존 선택값을 다른 항목 조작으로 버리던 계산을 교정하기로 했다. 서버 검색 모양은 보존하는 반면 트리 모양은 삭제해 같은 값의 표시 모양에 따라 저장 결과가 달라졌기 때문이다. 트리 밖 값의 상대 순서를 보존해 트리 안 값 뒤에 두는 것은 구현 선택이다.

0010의 선택 칸 1-2·1-5, 목록 2-5·2-6의 관련 판단을 이 결정으로 갱신한다. 동작 보장은 패키지의 `web-kit-list`·`web-kit-form` 스킬이 정본이다. DT·REF 적용과 트리 밖 값을 지우는 새 UI는 이번 범위 밖이다.

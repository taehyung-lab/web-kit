# 0016. 검색어 확정과 복사본 키 연결, 선택지 밖 값

- 결정일: 2026-10-30
- 결정권자: 사용자
- 대상: 5.0.0-rc.4

사용자 답변 “1B 2A 3B 4A 5 옵션에 없는 값이면 없는 걸로 6 키트에 안 올림”에 따라 검색어 확정과 키 연결의 책임을 바꾼다. 입력 칸에 남은 글자와 추가된 조건을 구별하고, 프로젝트가 Enter와 구분 문자를 자기 복사본에서 바꾸도록 패키지는 값 갱신 동작을 제공한다. DT의 별도 입력 결합 방법은 키트에 올리지 않는다.

선택지 밖 값을 보존했던 0015의 S3 판단을 대체한다. 전체 선택지와 서버 검색의 일부 결과를 구별하고, 선택지 준비 전의 값은 보존하기로 했다. 원본을 바꾸는 정리로 사용자 편집을 만들어 내지 않도록 표시·제출 값을 계산한다. Form.Choice는 준비 여부를 구별할 수 없던 기존 입구를 Form.Select의 같은 상태 계약에 맞춘다(조정자 2026-10-30 확인). 이 상태 연결은 기존 계약을 공유하는 예외이며 별도 동작 플래그는 만들지 않는다.

0010의 검색어·선택 칸 관련 항목과 0015의 트리 밖 값 판단은 이 결정으로 갱신한다. 동작 보장은 패키지의 `web-kit-list`·`web-kit-form` 스킬이 정본이며 이 문서에 다시 적지 않는다.

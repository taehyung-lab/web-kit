# 0012. 4.1 로그인 인증 단계의 공통 동작

- 출처: 2026-10-29 상위 DT 재구축 계획 합의 3·단계 1, 사용자 원칙 “로그인 로직은 REF 기준, UX는 1.5 기준”, A1 비교 질문 Q1–Q10에 대한 조정자의 사용자 원칙 적용 답변.
- 상태: 4.1 후보의 설계 결정. 최초 구현은 4.0.0-rc.3에서 출발한 4.1.0-rc.1이며, 현재 후보 번호는 패키지 manifest에서 확인한다. 원격 발행 결정이나 소비처 실서버 통과를 뜻하지 않는다.
- 적용: DT·REF는 이번 결정의 출처이며 새 소비처가 따라야 할 제품 기준이 아니다. 이 기능을 채택하면 아래 공통 동작을 사용하고, 인증 수단·서버 계약·시간 값·문구·화면 배치는 프로젝트가 정한다.
- 보장의 정본은 `packages/web-kit/skills/web-kit-auth/SKILL.md`다.

| 결정 | 이유 | 근거 |
|---|---|---|
| `/auth`는 로그인 전 인증의 계산·진행을 맡고 화면은 registry 복사본으로 둔다 | 인증 성공 뒤 세션과 인증 전 단계를 서로 섞지 않으면서 중복 구현을 없앤다 | 상위 합의 3, 0003 §4, 0011 |

| 만료 뒤 입력은 허용하고 확인·Enter 제출을 차단한다 | 만료된 코드의 제출은 막되 입력 편집과 다음 시도 준비는 허용한다 | Q3 답변. 최초 지시의 입력 잠금은 조정자가 근거 없는 조건으로 철회; 독립 판정 대상 |
